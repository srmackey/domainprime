# Weekly pack

Thin front. The four moves are `methodology/context-moves`. The ranked week is `methodology/nexus-board`. The desk has its own marks: implement, file, send, pause, throwaway. Do not restate the articles.

Triggers: `weekly pack`, `weekly review`, `update the board`, or a request to reconcile so context does not accumulate.

## Pass

1. **Board.** Do the weekly review `methodology/nexus-board` already defines. Show the board, forefronts, and stale flags. He sets the ranked lines. That write is his.
2. **Desk.** If `desk/` exists at this chair's root, list the filenames still there. Skip `README.md` and anything under `_archive/`. He marks each item implement, file, send, pause, or throwaway. An unmarked item is a pause and stays. File writes a capture to the library `raw/` and moves the file to `desk/_archive/`. Send writes a letter to the chair that can close it and moves the file to `desk/_archive/`. Throwaway deletes the file. Implement moves the file only once the work is done or he has named its home, and this pass does not start that work unless he says to do that item.
3. **Report and stop.** What moved, and what is still waiting. Do not open a node unless he names it.

If there is no desk, skip that step. Do not create one here.
