# Step-in

Before acting inside a project, read that project's constitution (`AGENTS.md`, falling back to `CLAUDE.md`, then `SYSTEM.md`/`README.md`) and operate under it for the duration of the work. This is doctrine, not optional context-gathering.

- **Closest file wins.** A deeper `AGENTS.md` overrides a shallower one.
- **Adopt modes and rituals.** If the target project defines modes, entering via its trigger phrases activates them exactly as if the session had been opened in that project.
- **Announce the step-in.** One line: which project, which constitution, which mode/lens if applicable.
- **Don't blend lenses.** When a session pivots domains, announce the switch and load the new constitution. Never carry one project's register into another.
- **Cross-project tasks:** read every involved constitution. Where rules conflict, the stricter privacy/safety rule wins, and each file edit follows the rules of the project it lives in.

## What crosses the boundary

Neither direction deposits.

- **What you carried in does not get deposited.** A sitting that arrives with cross-project context, such as a spec slice or a sweep, knows things this node cannot see and cannot close. That knowledge does not go into this node's records. Write here only what this chair could have found on its own and can act on. The node's own exit ritual makes this write look legitimate, so the discipline has to be yours.
- **What you notice here for another chair does not stay here.** A finding this chair cannot close is not an open loop here. The item names the chair that can close it. It leaves as a carry-back when this same sitting will hold that chair again, and as a letter when it will not. Walking back through an intermediate nexus does not write the item there. `methodology/carry-back` holds that choice and the rule that converts one into the other, one letter per item still held at the end. A named slice on a spec this sitting is executing is closed on that spec, including a write of that file. Side work that is not a slice leaves as mail. Neither write is a deposit into this node.
- **A citation is not a deposit.** Where this node's work originates in a paper held elsewhere, a pointer to that paper may be written here: a line naming it, and nothing more. The originating context, reasoning, and sequencing stay where they are. The carve-out is this narrow on purpose, and without it the rule above would correctly refuse the pointer.

## Settle the state, not only the doctrine

The constitution says how this chair works. The records say what is already in flight. A chair whose own constitution happens to require a status read is not the general case; this is.

- **Before the work, settle this chair.** You have adopted its lens, so the run is that chair settling its own records, which is what `methodology/settle` means by naming step-in as a trigger. The nexus still never settles a node from outside. What a run covers is whatever settle contracts this chair composes, plus any surface its own constitution names as its state that no contract reaches, such as a pending inbox. Do not hand-walk those surfaces here and do not restate what a contract already says.
- **Filter to the work in hand.** This is not a full reckoning of the node, and not a report of the node back to itself. You want the subset that bears on what you are about to do: an open loop that contradicts it, a pending letter about it, a next step that already covers it, a decision waiting on the principal that this work would presume. Say what you found in one line before starting. If nothing bears on it, say nothing.
- **Status is on request.** Do not recite Forefront or the status sections on entry. He gets them when he asks (`methodology/status-contract`; at a nexus, the pack in `methodology/nexus-board`). If this turn has not already offered, one sentence offering to check status is enough. When this chair has a desk and the count is not zero, that sentence leads with the count.
- **A record entry can stop the work.** If what you read means the task should not proceed as asked, name it and wait. That is the same hard stop the charter already requires, reached through the records instead of through the constitution.

The exit ritual closes the other half. What you learn about this chair goes back into the same records the next step-in will read.
