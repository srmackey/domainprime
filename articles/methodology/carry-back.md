# Carry-back

An item noticed inside a chair that this chair cannot close. The sitting holds a list. Each item names the chair that can close it. Discharge that item when that chair is back in front of the session. Walking back through an intermediate nexus does not write the item into that nexus.

One agent holds the chain. What a chair notices for another chair does not have to be written down and read back to survive the walk.

## Carry-back or letter

| Condition | Instrument |
|---|---|
| The same agent will hold the named chair again before this sitting ends | Carry-back |
| It outlives the sitting, or the named chair is one this sitting will not hold | Letter, per `methodology/envoy-mail` |

- A finding for the parent nexus, noticed inside one of its nodes, while this sitting will return to that parent: hold it for the parent.
- A finding for a chair above that parent, noticed inside a node: hold it for that chair. Pass back through the child nexus without filing it there.
- A finding for a chair this sitting will not hold again: a letter now.

A dossier is a file inside the current chair. Loading one does not add a lens. Something that belongs in the dossier is written there. Something that chair cannot close is a carry-back or a letter from that chair.

## What makes the lighter instrument safe

**A carry-back not discharged before the sitting ends becomes a letter to the chair it names.** One letter per item. Automatically, without asking. The letter is the durable copy, so writing one destroys nothing and `methodology/autonomy-gate-provenance` passes.

That conversion is the whole warrant for holding something outside mail. Without it a carry-back is an intention living in one session's head, which is the case the provenance gate names as having no second copy at all.

**Discharging one is settled work.** It is what the sitting already undertook when it picked the item up. It does not come back as a proposal, and the principal does not restate it.

## Vocabulary

Purview, not capability. "That is not this chair's purview, holding it for the chair that can close it," and then actually doing it when that chair is back. Never "I can't do that from here," which claims a limit the agent does not have and hands the work back to whoever is reading.

Relation to `methodology/step-in`: that article bars depositing what you carried in, and bars filing a carry-back into an intermediate nexus on the way back. This is where the item goes instead. The item names its chair. The two are one rule seen from either side of the boundary, and neither is complete alone.

Relation to `methodology/settle`: carry-backs held by the sitting are in a settle run's scope. Discharge the item when the run is in the chair it names. Convert what is still held only when the sitting ends, one letter per item. A run in a chair the item does not name does not file it and does not turn it into a letter.

Reason: the alternative to holding it is writing a letter to a chair the same agent is about to occupy, which pays mail's full cost to cross a boundary that exists only in the protocol. The alternative to filing it in the nexus being walked through is that nexus owning a line it cannot close. The alternative to holding it in nothing at all is losing it, which is what mail was built to prevent. The instrument is lighter than mail; the conversion rule is what keeps it as reliable.
