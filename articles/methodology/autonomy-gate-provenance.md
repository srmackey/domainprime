# Autonomy gate: provenance

An autonomy gate names the condition under which an agent acts without asking. This
gate opens on provenance.

> A record entry may be corrected, closed, or removed without asking when what it
> says is recoverable from somewhere else. Ask only when the entry is the only copy.

**Counts as another copy:** a commit, tag, or release; a landed spec or plan paper;
an archived inbox letter and its `_log.md` row; a published sitrep; the file the line
points at; a library page.

**Does not count:** an intention that was never written anywhere else; a decision
made in conversation that only this line records; an open loop whose whole content is
a question waiting on the principal.

**Three outcomes, in order:**

| Test | Action |
|---|---|
| Passes | Settle it. Report it in one line. Do not ask. |
| Fails, and a durable home is obvious | Write the second copy first, then settle the line. Report both moves. |
| Fails, and no durable home is determinable | Leave it. Surface it. This is the only case that costs him a turn. |

**The failure mode is never deletion and never a question. It is promotion.** An
agent that cannot clear a line clears it by giving it a home.

Promotion moves content to the home it should have had. It does not open a second
ledger: once the durable copy exists, what stays behind is a pointer or nothing.

**Where it applies.** Any record this chair keeps: the sections of its state file,
its published sitrep, its mail, its inbox, the state on its papers. Not the board,
which is the principal's and is never settled by an agent.

The gate is about permission to act, not about scope. It never widens what this chair
may touch, and a destructive, outward-facing, or sensitive-chair check that fires
independently still fires.

Reason: the older shape gated on what kind of edit was being made, which needs
judgement every time and produces a round trip every time. Whether the entry is the
only copy is checkable at the moment of action, without asking. A record whose upkeep
costs more turns than the record saves is not worth keeping, so this gate is what
makes the rest of the ceremony affordable.
