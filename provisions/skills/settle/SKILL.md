# Settle

Thin front. The rules are `methodology/settle`, and each surface's definition of settled lives in that system's own article. Do not restate either here.

## Run

1. **Collect the contracts.** Read this chair's composed protocol for sections headed `Settle contract`. Each declares a tier and a surface. That set is the scope. There is no list to look up and nothing to keep in sync.
2. **Order them:** sources, then digests, then publications. Then add the surfaces settle owns directly: anything this chair's constitution names as working state, whatever Forefront points at, and carry-backs held by this sitting.
3. **Read before fixing.** Walk the surfaces in that order and collect findings across all of a surface's sections together. Fixing as you read hides duplicates, because a duplicate is only visible once both places have been read.
4. **Gate each finding.** Passes: act. Fails with an obvious durable home: write the second copy first, then act. Fails with no determinable home: leave it and hold it for the report.
5. **Write.** Settled work only, on this chair's surfaces only. Never the board.
6. **Report** in the article's shape, then stop.

## Stop conditions

- Do not begin the work the run made visible. Finishing a settle is not permission to start.
- Do not process an inbox, triage mail, or author a paper. Those stay on command.
- Do not settle another chair, and do not settle a node from the nexus.
- A settle-pass may step into each chair in its scope and run this procedure there. Reaching a chair you have not stepped into is still refused.
- If a finding needs a decision that is the principal's, it goes below the report. It is not resolved by deletion and not resolved by asking mid-run.
- If Envoy is unreachable, skip its contracts and say so in the report. The files still hold the work.
